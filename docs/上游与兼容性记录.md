## DSM 目标差异

上游 Motrix 2.4.7 已包含原生 Synology SPK、Web UI、Aria2、下载目录选择与共享目录授权流程。上游 Synology 文档声明最低 DSM 为 `7.2.2-72806`，并将 DSM 6 列为目标范围之外。

本项目目标为 `DS3615xs-j / Bromolow / DSM 6.2.3-25426`。需在适配时逐项验证：

1. DSM 6.2.3 的 SPK 安装字段、生命周期脚本和应用菜单入口。
2. Bromolow/DSM 6.2.3 官方工具链下 Node、Aria2、SQLite 原生扩展及文件系统助手的 ABI。
3. DSM 6.2 的套件运行身份、共享文件夹权限、用户认证和 Web 入口。
4. Web UI 对可用共享文件夹的浏览、授权和用户自选保存路径。
5. 启停、重启、升级保留、卸载保留/删除，以及真实 HTTP 与 BT 下载。

不通过仅改写 `os_min_ver` 来认定支持 DSM 6。每项通过状态都要附实际构建或 NAS 结果；目标 NAS 上的安装、升级和下载验收目前尚未记录。
